# Dataset Information

This directory contains the datasets used during the development,
training, preprocessing, and evaluation of the Disaster Relief Aid
Prediction system.

## Dataset Categories

The project uses data related to:

- Historical disaster events
- Population information
- Infrastructure and health-centre information
- Disaster input records
- Cleaned and merged training data
- Geospatial information
